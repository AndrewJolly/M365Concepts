Event-based retention using Date Closed

This interactive diagram drills into a Microsoft Purview implementation where Business Classification metadata drives automatic label application, while a separate Date Closed value is used later to start retention through periodic Purview events. The focus here is not on every possible retention pattern, but on how this specific operating model works in practice, what it depends on, and where the control points sit.
